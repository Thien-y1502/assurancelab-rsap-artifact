# RSAP v2 theory boundary

The implementation audit enumerates all 1,024 binary loss sequences of length
10 and checks exact wealth agreement with an independent arithmetic recurrence.
It also verifies the predictable-factor expectation inequality at lambda values
0, 0.25, 0.5, 0.75 and 1.0.

This supports the declared bounded certificate contract. It is not a proof of
the full adaptive-filtration theorem for arbitrary action policies. The
remaining theory gate is a formal supermartingale/Ville proof with measurable
policy assumptions.
